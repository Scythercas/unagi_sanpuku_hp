# 画像トリミング指示書（老舗案・ギャラリー石垣状レイアウト前提）

`画像-20260929T114330Z-1-001/画像/` の採用写真（ファイル名に「〇」付き）を、Windows 標準の「フォト」でトリミングし、microCMS に登録できる状態にするための手順書。上から順に進めれば迷わないように書いてある。

- 対象デザイン：老舗案（`feature/design-shinise`）
- ギャラリーの並べ方：写真ごとの縦横比を活かして並べる（当初の方針C＝石垣状から、実装では**高さ揃えの横並び**に変更。切り抜かず、縦長・横長のまま表示する）
- 作業時間の目安：16枚で 40〜60 分

---

## 0. 前提として決まっていること

| 項目 | 決定内容 |
|---|---|
| 採用する写真 | ファイル名に「〇」が付いたものだけ（例外：`〇手前だけ切り取る` は対象外） |
| 〇IMG_3589 と 〇IMG_3590 | ほぼ同じ構図のため **〇IMG_3590 だけ**をギャラリー「料理」に使う。〇IMG_3589 は使わない（皿の縁が左右とも写り、収まりが良いため） |
| ヒーロー／OGP の元写真 | **〇IMG_3183**（焼き台）。ギャラリー「調理」の表示順を1番にする |
| ギャラリーの比率 | **3:4（縦）か 4:3（横）のどちらか**に揃える。細長い 9:16 / 16:9 は使わない（石垣状でも1枚だけ飛び出して並びが崩れるため） |
| おしながきの比率 | **正方形**（表示枠が 112px の正方形のため） |
| 画質の下限 | 短い辺 900px 以上（全写真クリア済み） |

## 1. 準備（最初に1回だけ）

1. **保存先フォルダを作る**：デスクトップなど**リポジトリの外**に `さんぷく_トリミング済み` フォルダを作り、その中に次の5つのフォルダを作る。
   ```
   さんぷく_トリミング済み/
   ├─ 1_外観
   ├─ 2_内装
   ├─ 3_調理
   ├─ 4_料理
   └─ 5_おしながき
   ```
   > 元写真フォルダ（約150MB）もリポジトリ直下から外へ移すと、誤って Git にコミットする心配がなくなる。
2. **「フォト」を最新にする**：Microsoft Store →「ライブラリ」→「更新プログラムを取得」。手順 3-4 で使う「消しゴム」機能が古い版には無い。

---

## 2. フォトの基本操作（全写真共通）

以降の手順で「基本操作」と書いたら、この流れを指す。

1. 写真を右クリック →「プログラムから開く」→「フォト」。
2. 画面上部の「画像の編集」（鉛筆アイコン）をクリック（`Ctrl+E` でも可）。
3. 「トリミング」タブを開く。
4. 画面下部の**縦横比**メニューで、指定の比率を選ぶ。
5. 枠の**四隅**をドラッグして大きさを決める。**写真側**をドラッグすると、枠の中で写真が動く。
6. 右上の「保存オプション」の ▼ →「**コピーとして保存**」。
   - **「保存」は押さない**（原本が上書きされる）。
   - 保存先は手順 1 のフォルダ、ファイル名は各手順で指定した名前にする。形式は JPG のまま。

### 縦向きの 3:4 の選び方

縦横比メニューに縦向き（3:4）の切り替えがあればそれを使う。無い場合は「**自由**」を選び、目で見て「高さ ≒ 幅 × 1.33」になるよう合わせる。保存後に手順 5 の確認表と照らし合わせ、範囲内なら OK。

### 3-4. 車のナンバーを消す（#4 だけ）

1. 基本操作の 1〜2 で編集画面を開く。
2. 「**消しゴム**」（生成消去）を選ぶ。
3. ブラシの大きさをナンバープレートより少し大きめにし、**左下の白い車**と**右端の車**のナンバーをなぞる。
4. 拡大（`Ctrl` + マウスホイール）して、文字が読めないことを確認する。
5. 不自然に崩れる場合は `Ctrl+Z` で戻し、代わりにトリミングで車が枠の外に出るよう**下と左右を削る**（4:3 を維持）。
6. 続けて「トリミング」タブで **4:3** を選び、**建物が中央**に来るよう左右を削る → 「コピーとして保存」。

## 5. 仕上がり確認

保存したファイルを右クリック →「プロパティ」→「詳細」タブで**幅・高さ**を見て、次の範囲に入っていれば OK。

| 種類 | 幅 ÷ 高さ | 例 |
|---|---|---|
| 縦（3:4） | 0.72〜0.78 | 960×1280、3024×4032 |
| 横（4:3） | 1.28〜1.38 | 1280×960、4032×3024 |
| 正方形 | 0.97〜1.03 | 1500×1500 |

チェックリスト：

- [ ] 16枚すべてが手順 1 のフォルダに保存されている
- [ ] 原本が上書きされていない（元フォルダの更新日時が変わっていない）
- [ ] `外観_04.jpg` でナンバーが読めない
- [ ] おしながきの4枚が正方形で、料理が枠いっぱいに写っている
- [ ] 短い辺がすべて 900px 以上

## 6. 次の工程（microCMS 登録時の対応表）

トリミング後、microCMS に登録するときは次のとおり入力する。**ヒーロー画像は「調理」で表示順が一番小さい写真**から自動で選ばれるので、`調理_01.jpg` の `order` を必ず調理の中で最小にする。

### gallery

| ファイル | type | order |
|---|---|---|
| 外観_01〜04 | 外観 | 10, 20, 30, 40 |
| 内装_01〜03 | 内装 | 50, 60, 70 |
| 調理_01 | 調理 | **80**（ヒーロー／OGP） |
| 調理_02 | 調理 | 90 |
| 料理_01〜03 | 料理 | 100, 110, 120 |

> `order` を10刻みにしておくと、後から間に写真を差し込みやすい。キャプションは任意。

### menu

`menu_*.jpg` を、上の表の「紐づけるメニュー」のレコードの `image` にアップロードする。
