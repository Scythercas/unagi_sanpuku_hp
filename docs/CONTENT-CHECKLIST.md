# 顧客確認・素材チェックリスト

着手前〜制作中に店主／ご子息へ確認する事項。**負担を下げるため、開発者が推奨デフォルトやドラフトを用意し、店主にはイエス/ノーの確認だけを求める**。

## A. 最優先（着手前に確定）

- [ ] **ドメイン綴りの確定**：既定は `sanpuku-unagi.com`（Instagram の綴りと一致）。
  - アンダースコア（`sampuku_unagi.com`）は**不可**。ハイフンか区切り無し。
  - 候補：`sanpuku-unagi.com` / `sanpukuunagi.com` / `sampuku-unagi.com`。
  - Instagram（`sanpuku_unagi`）と表記を揃えるなら `sanpuku-unagi.com` を推奨。
- [ ] **一言紹介の承認**：開発者が 1〜2 文のドラフトを用意 →「これで OK か」だけ確認。
- [ ] **写真素材の棚卸し**：外観／内装／調理／料理の 4 種で既存 Instagram 写真を仕分け。
  - [ ] 「調理中（蒲焼きを焼いている画）」があるか。無ければ**追加撮影の第一候補**。
- [ ] **Instagram 写真の権利**：撮影者が別にいる場合、サイト利用可否を確認。
